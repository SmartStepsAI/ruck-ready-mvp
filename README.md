# Ruck Ready MVP

Digital leader’s book and Soldier readiness tool. Includes:
- Mental health check-ins
- ACFT PT programming
- Nutrition guides
- Lingo Buddy (Spanish/Portuguese)
- NCO Study Guide
- Leader Book with Bullet Creator

## Deploy to Firebase

1. `npm install`
2. `firebase login`
3. `firebase init`
4. `firebase deploy`
